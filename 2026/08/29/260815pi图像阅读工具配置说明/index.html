pi 图像阅读工具（GLM-4V）配置说明

  • 创建日期：2026-08-15
  • 工具类型：pi extension（非标准 MCP，见下文说明）
  • 状态：已部署并测试通过（2026-08-15，字符测试图验证）

一、工具概述（What / Why）

功能：在 pi 中输入本地图像路径，通过智谱视觉语言模型 GLM-4V 理解图像内容，返回认知描述文字（主体、场景、字符/文字、明显异常等）。

为什么不是标准 MCP：pi 官方不支持 MCP 协议（无 MCP client），其原生等价方案是 extension + registerTool() 注册自定义工具供 LLM 调用。本工具按 pi extension 实现，效果等同。

能力边界（重要）：

  • ✅ 适用：图像内容描述、印刷字符/文字提取、主体/场景/状态识别、明显异常辅助判断
  • ❌ 不适用：产线细小瑕疵检测（污点/蚊虫/黑胶布/微小破口等）——精度远不如专用 OpenCV/HALCON 算法，不可替代瑕疵检测

二、文件组成与位置

  • pi 启动时自动发现并加载；修改代码或 key 后在 pi 中执行 /reload 热重载，无需重启 pi
  • 仅对当前 Windows 用户全局生效（所有项目可用）

三、配置步骤

  1. 获取 API key：https://open.bigmodel.cn 注册 → 控制台获取 API Key
  2. 写入 key 文件：把 key 粘贴到 apikey.txt（一行纯文本）
  3. 重载：pi 中执行 /reload
  4. 验证：对 pi 说”分析 G:\xxx.bmp，描述内容”，观察是否调用 analyze_image 工具并返回描述

可选：环境变量方式（优先级高于 key 文件）

环境变量 作用 默认值
GLM_API_KEY（或 ZHIPUAI_API_KEY / ZHIPU_API_KEY） API key 无（回退读 apikey.txt）
GLM_MODEL 默认模型 glm-4v-flash
GLM_BASE_URL 接口地址（换厂商用） 智谱 OpenAI 兼容端点

注意：环境变量在 pi 进程启动时继承，修改后需重启 pi；key 文件方式只需 /reload，日常推荐后者。

四、使用方法

直接用自然语言，LLM 会自动调用工具：

工具参数（一般由 LLM 自动填，也可在对话中口头指定）：

参数 必填 说明
imagePath 是 本地图像路径（支持 jpg/png/bmp/gif/webp；BMP 自动转 PNG）
question 否 关注点指令，如”这张图有哪些明显缺陷”；省略则整体描述
model 否 默认 glm-4v-flash（免费）；glm-4v / glm-4v-plus 更强但收费
maxTokens 否 返回上限，默认 1024

五、内部处理流程

六、常见问题排查（实际踩坑记录）

现象 原因 解决
HTTP 429 / code 1113 余额不足 账户无该模型额度（glm-4v 收费） 用免费模型 glm-4v-flash（已设为默认），或充值
HTTP 400 / code 1210 参数有误 BMP 格式不被 GLM-4V 接受 已内置 BMP→PNG 自动转换；若仍报错检查 BMP 是否为压缩格式（如 RLE）
未配置智谱 API key apikey.txt 缺失且无环境变量 写入 key 文件后 /reload
HTTP 401 key 无效 核对 key，必要时去控制台轮换
大图失败 超过云端大小/分辨率限制 缩小图像后重试（代码对 >10MB 有提示）

七、维护

  • 换 key：轮换安全 key 时，新 key 直接写入 apikey.txt → /reload
  • 换模型：对话中指定 model 参数，或改 index.ts 中 DEFAULT_MODEL，或设 GLM_MODEL 环境变量
  • 换厂商（如豆包/Gemini）：改 GLM_BASE_URL 指向新端点 + 换 key；代码为 OpenAI 兼容格式，多数厂商可直接复用
  • 日志：工具调用结果中的 usage 信息（token 消耗）记录在 tool details 中，可在 pi 中查看

八、新电脑部署指南（面向另一台电脑的 pi agent / 新成员）

本章目标是：在另一台电脑上，仅凭本文档即可完成安装，不踩坑。
面向 pi agent 执行时，可直接按步骤逐条执行命令/文件操作。

源码位置（自包含）：本文档末尾【附录 A：extension 完整源码】，与本机运行版本完全一致。

安装步骤：

  1. 确认目标机已安装 pi（pi --version 可执行）
  2. 创建目录，将【附录 A】完整源码内容保存为以下文件（UTF-8 编码，文件名 index.ts）： （即 C:\Users\<目标机用户名>\.pi\agent\extensions\image-analyzer\index.ts，目录不存在则创建）
  3. 配置 API key：在同目录创建 apikey.txt，一行写入智谱 key
    （获取：https://open.bigmodel.cn 控制台；或复制源机 apikey.txt）
  4. 加载：启动 pi（新会话自动加载）；若 pi 已在运行，执行 /reload 热重载
  5. 验证：对 pi 说”分析 <任一本地图像路径>，描述内容”，确认调用了 analyze_image 工具并返回描述文字；报错则按下方踩坑清单排查

踩坑清单（源机已实际踩过，代码已内置规避，供排障对照）：

坑 规避方式 代码是否已内置
BMP 图像被云端拒收（HTTP 400/1210） BMP 自动转 PNG 后上传（支持非压缩 8/24/32 位；RLE 压缩 BMP 不支持，需先转格式） ✅
图像 base64 格式不兼容（智谱原生 vs OpenAI data URL） 自动双格式尝试，400 时回退 ✅
glm-4v / glm-4v-plus 收费，账户无余额报 429/1113 默认模型设为免费的 glm-4v-flash ✅
key 环境变量改动不生效 环境变量在 pi 启动时继承；优先用 apikey.txt（改后 /reload 即生效） ✅
额外依赖安装 零依赖（仅 Node/Bun 内置 + pi 自带 typebox），无需 npm install ✅
超大图像 >10MB 有提示；云端对分辨率/大小有限制，失败时缩小图像重试 提示

卸载/禁用：删除或移走 %USERPROFILE%\.pi\agent\extensions\image-analyzer\ 目录后执行 /reload。

九、安全提醒

  • apikey.txt 为明文存储，请勿将该目录纳入同步/备份/版本库
  • key 若曾在聊天等明文场合出现过，建议在智谱控制台轮换

附录 A：extension 完整源码（index.ts）

将以下内容完整保存为 %USERPROFILE%\.pi\agent\extensions\image-analyzer\index.ts（UTF-8 编码）。
零外部依赖，无需 npm install。与本机运行版本一致。
